# AfterHours: The Behavioral Intelligence Layer of Finance 🛰️🧠

**AfterHours** is a production-grade, AI-native trading platform designed to solve the retail liquidation crisis. It serves as the world's first **Behavioral Risk Middleware**, sitting between high-risk institutional signals and individual traders.

---

## 🚀 The Core Innovation: "Smart Signal Translation"
Social trading today is dangerous. Followers blindly copy institutional "whales," leading to account wipeouts due to leverage mismatches. **AfterHours** fixes this by "translating" every signal through your unique **Trade DNA**.

> *"We don't just follow leaders; we audit them through your psychology."*

---

## 🧠 Key Features

### 1. Trade DNA Engine (Psychological Genetics)
Quantifies your trading "genetics" via historical audit and conversational analysis.
*   **Archetypes:** Precision Architect, Safe Haven Guard, Aggressive Scalper.
*   **Visuals:** Interactive 5D Radar Charts showing Risk, Patience, and Discipline.

### 2. Aura AI Assistant (Autonomous Guardian)
An empathetic, signal-aware companion that acts as your 24/7 strategic desk.
*   **Contextual Intelligence:** Aura knows your DNA and current emotional state.
*   **Anti-FOMO Guard:** Autonomously restricts trading execution if psychological instability is detected.

### 3. Signal Intelligence Center
A high-fidelity dashboard that translates institutional "Alpha" into personalized orders.
*   **Explainable AI (XAI):** Clear rationale for every Stop-Loss and Leverage adjustment.
*   **Live Neural Logs:** A real-time terminal feed of Aura's strategic audit process.

### 4. Hall of Alpha (Social Discipline)
A leaderboard that ranks users based on **Discipline, Safety, and Consistency** rather than just raw profit.

### 5. Nexus Command CMS
A secure, role-based administrative portal for managing institutional signals and monitoring global ecosystem health.

## 🛠️ Technical Stack
*   **Frontend:** Next.js 14, Tailwind CSS 4, Recharts, Lucide Icons, Framer Motion.
*   **Backend:** FastAPI (Asynchronous), SQLAlchemy 2.0, SQLite (Dev) / MySQL (Prod).
*   **Intelligence:** Autonomous risk-scoring engines, DNA-Signal translation matrices.
*   **Communication:** WebSocket-ready for instantaneous signal pulses.

## 🏃 Quick Start (Hackathon Demo)

### 1. Seeding the Ecosystem
Ensure the demo environment is hydrated with realistic data:
```bash
cd backend
python seed.py
```

### 2. Launching the Backend
```bash
cd backend
uvicorn app.main:app --reload
```

### 3. Launching the Terminal (Frontend)
```bash
cd frontend
npm install
npm run dev
```
